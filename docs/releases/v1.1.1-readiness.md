## Version, compatibility, and consent

- Version `v1.1.1`, Android/build code `68`; public 1.1.0 used 67. Same-key Android updates retain `cn.com.letalk.navo` data. Windows ProductVersion becomes `1.1.68`, preserving upgrade UUID `1560D807-E123-4B05-B883-B9B8EF9FD46C`.
- Local `2.12.x` development installations still need a manual 1.x download; back up settings and uninstall the Windows development installer first. Android build 68 can replace 65–67 with the same key.
- Settings, accounts, playlist bookmarks, and generated-station sync schema 2 are unchanged. Connect protocol remains v1 with additive discovery/Welcome fields; existing trusted peers remain supported. Use 1.1.1 on both devices for the complete new flow. Older devices may need selection from Nearby.
- Showing a code authorizes connection. Trusted devices can apply account setup without another target-side approval. Show codes only to trusted devices. The controller explicitly chooses sign-in (active account and portable settings), playback, or neither; dismissing the sheet sends nothing.
- Android backups and device transfer exclude Connect trust and secrets because their Keystore keys cannot be restored. After reinstall/restore/transfer, reconnect using a fresh code when needed and forget obsolete duplicate device entries. This does not require re-pairing for ordinary in-place upgrades.
- Immediate offline startup is limited to Offline Mode or Android reporting no network. Desktop has no native connectivity fact; with Offline Mode off, Windows startup or a server outage while the OS appears connected can still wait for provider timeouts. Background recovery preserves downloaded playback, respects Offline Mode and stops automatic retries for rejected accounts/certificates. Offline Mode is not a guarantee of zero network traffic throughout the app.
- Distribution remains Windows x64 ZIP/MSI/EXE and signed Android APK for API 26+. AAB, mapping and native-symbol support artifacts remain in Actions. Windows packages are not publisher-signed. Apple/Linux pipelines and all fork store distribution remain disabled/unavailable.
