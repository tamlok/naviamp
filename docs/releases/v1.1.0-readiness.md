- Version `v1.1.0`, Android/build code `67`. Public 1.0.0 used code 66. Same-key Android build 67 updates 65/66 in place; app ID remains `cn.com.letalk.navo`.
- Windows installer ProductVersion is `1.1.67`, retaining upgrade UUID `1560D807-E123-4B05-B883-B9B8EF9FD46C`. Public 1.0.0 upgrades normally. Local `2.12.65` development installers still require a settings backup and manual uninstall before installing 1.x; the SemVer updater does not offer a downgrade.

- Distribution remains Windows x64 ZIP/MSI/EXE and signed Android APK for API 26+. AAB, mapping, and native-symbol files stay in Actions support artifacts. Windows is not publisher-signed. No store, Apple/Linux, physical-vehicle, or native-listening acceptance is implied by local JVM tests.
